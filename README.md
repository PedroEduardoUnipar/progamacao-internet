# Programação para Internet

Repositório acadêmico com aulas práticas, atividades e projetos desenvolvidos na disciplina de Programação para Internet da Universidade Paranaense (UNIPAR).

## Organização

- `aulas/javascript/` — exemplos e exercícios de JavaScript realizados em aula.
- `atividades/` — atividades práticas da disciplina.
- `bimestres/1-bimestre/` — materiais e trabalhos do primeiro bimestre.
- `bimestres/2-bimestre/` — materiais e trabalhos do segundo bimestre.
- `projetos/` — projetos desenvolvidos durante a disciplina.
- `poo/` — material relacionado às aulas de Programação Orientada a Objetos.
- `materiais/` — arquivos gerais e materiais consolidados da disciplina.

Os arquivos compactados foram mantidos sem alterações internas; apenas foram reorganizados em pastas para facilitar a navegação e preservar o conteúdo original.
