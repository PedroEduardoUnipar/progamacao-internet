# Programação para Internet

Repositório acadêmico com aulas práticas, atividades e projetos desenvolvidos na disciplina de Programação para Internet da Universidade Paranaense (UNIPAR).

## Objetivo

Centralizar os exercícios de desenvolvimento web realizados durante a disciplina e manter o conteúdo organizado por contexto acadêmico e período.

## Tecnologias estudadas

- HTML
- CSS
- JavaScript
- fundamentos de desenvolvimento web
- organização de projetos front-end

## Estrutura

- `aulas/javascript/` — exemplos e exercícios de JavaScript realizados em aula
- `atividades/` — atividades práticas da disciplina
- `bimestres/1-bimestre/` — materiais e trabalhos do primeiro bimestre
- `bimestres/2-bimestre/` — materiais e trabalhos do segundo bimestre
- `projetos/` — projetos desenvolvidos durante a disciplina
- `poo/` — materiais relacionados a Programação Orientada a Objetos
- `materiais/` — arquivos gerais e conteúdos consolidados

## Organização dos arquivos

Parte do conteúdo foi originalmente armazenada em arquivos `.zip` e `.rar`. Esses arquivos foram mantidos sem alterações internas e reorganizados em pastas para preservar o material original e facilitar a navegação.

## Contexto acadêmico

Este repositório representa parte da evolução nos estudos de desenvolvimento para web durante a graduação em Análise e Desenvolvimento de Sistemas.
